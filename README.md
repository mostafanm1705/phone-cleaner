# Phone Cleaner

Android cleaner for Samsung Galaxy A34 (Android 11+). Scans the whole phone and lets you review before deleting.

**Download:** https://github.com/mostafanm1705/phone-cleaner/releases/latest/download/PhoneCleaner.apk

Features: junk files, empty folders, APK installers, leftovers of removed apps, exact duplicates, similar photos, blurry and low-resolution photos, old screenshots, WhatsApp media, large files, battery-draining apps, unused apps, app cache, permission audit, device health, 7-day trash with restore. Arabic / English.

Built automatically by GitHub Actions on every push to `main`.
